## The Post

Ever stare at a git commit message box like "uhhh... fix stuff"? 👀

Yeah, we've all been there.

So I built **Commit-AI** 🤖✨ - because life's too short for boring commit messages (and let's be real, nobody remembers what they changed 5 minutes ago).

Here's what makes it kinda fire:

🎯 **AI-Powered Commits** - Just stage your files, run `cmt`, and boom. Your commits go from "fixed bug" to actually descriptive messages that your future self (and your team) will thank you for.

🔍 **Built-in Code Review** - Before you commit that sus code at 2am, Commit-AI can review it for security issues, performance problems, and best practices. It's like having a senior dev looking over your shoulder, but less intimidating.

📚 **Smart Standards** - Import style guides from React, Angular, Vue, Node, Python, Java, Go, Rust, TypeScript, or C#. Or create your own. The AI actually follows them.

⚡ **Works with Your Setup** - OpenAI, Claude, Gemini, DeepSeek, Ollama, Mistral - pick your poison. Even works with local models if you're into that privacy life.

🎨 **Git Hooks & Automation** - Set it up once, forget about it. Automatic commit messages in your flow.

💾 **Caching** - Reviews the same code? Cached. Your wallet (and time) will thank you.

The best part? It's **open source** and **free**. No paywalls, no BS. Just grab it from npm and start vibing:

```bash
npm install -g @mantisware/commit-ai
```

Or if you're fancy:
```bash
pnpm install -g @mantisware/commit-ai
```

Then just run `cmt` in any git repo and watch the magic happen ✨

Been using it for a few months now and honestly can't imagine going back to writing commit messages manually. It handles massive diffs automatically, splits them up smart, and just... works.

Plus it has a heartbeat feature that shows you how long the AI is thinking. Because waiting without feedback is lowkey anxiety-inducing.

Check it out: https://github.com/MantisWare/commit-ai

Would love to hear what y'all think! Drop a comment if you try it out 👇

## Key Talking Points (for comments/responses)

- **Why build this?** Fed up with bad commit messages in my own repos. Realized everyone has this problem.

- **What makes it different?** Most tools just do commit messages. This does code review, follows standards, caches results, and works with any AI provider.

- **Privacy concerns?** Works with local models (Ollama) or self-hosted endpoints. Your code doesn't have to leave your machine.

- **Cost?** Free tool. You just need an API key for your chosen AI provider. Or use Ollama for 100% free.

- **For teams?** Yes! You can share `.commit-ai-standards` files in your repo. Whole team gets consistent commit messages and reviews.
